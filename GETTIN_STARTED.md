# Getting Started

This guide will help you set up your environment and begin learning cybersecurity.

No previous cybersecurity experience is required.

## 1. Join Club Communication

Make sure you are connected to the club's communication platforms.

You should:

- Join the Cyber Club Discord.
- Join the university Cyber Club organization.
- Check the announcements channel regularly.
- Introduce yourself.
- Attend club meetings and workshops.
-   Thursdays @7:00pm in Brinkley 215

## 2. Create Your Accounts

Create accounts for the platforms used by the club.

Recommended accounts include:

- GitHub
- TryHackMe

Additional platforms may be introduced during meetings and competitions.

## 3. Set Up Your Environment

For Windows users, the recommended starting environment is:

Windows 11

to

WSL2

More advanced members may also want to use:

- Kali Linux
- VMware
- VirtualBox
- Dedicated Linux systems
- Cybersecurity lab environments

Virtual machines are strongly recommended when working with software or configurations that could affect your primary operating system.

## 4. Learn the Fundamentals

Before focusing on advanced cybersecurity topics, become comfortable with:

- Linux
- Networking
- Git
- Python
- Bash
- Basic Windows administration
- Cybersecurity fundamentals

Start with:

- [Linux Fundamentals](resources/linux.md)
- [Networking Fundamentals](resources/networking.md)
- [Programming Fundamentals](resources/programming.md)
- [Cybersecurity Fundamentals](resources/cybersecurity.md)

## 5. Practice

Cybersecurity requires hands-on practice.

### picoCTF

Practice:

### TryHackMe

Practice:

- Linux
