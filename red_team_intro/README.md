# ***Red Teaming***
  ### Red teaming is the process of doing cyberattacks to identify and exploit vulnerabilities in an organization’s systems, people, and processes.

# General Overview:

  ## 1- Get permission from an Organization

  Companies will give you a scope (what you can and can't do) and documents that you sign that allow you to ethically hack them (penetration test them).

  ## 2- Start Reconnaissance

  First you want to find out information about the system you are attempting to hack. This starts out with finding open ports, service versions, what operating system the /
  computer is running, etc... This will allow you to have an idea of where to start.
