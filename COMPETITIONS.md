# Cybersecurity Competitions

The Cyber Club participates in several cybersecurity competitions.

Competitions provide members with practical experience, teamwork, technical skills, and opportunities to represent the university.

## National Cyber League

NCL is a cybersecurity competition covering several areas of cybersecurity.

Common challenge categories include:

- Open Source Intelligence
- Cryptography
- Password Cracking
- Log Analysis
- Network Traffic Analysis
- Forensics
- Web Application Security
- Enumeration and Exploitation

Recommended experience level:

Beginner to Advanced

NCL is a good first cybersecurity competition.

---

# Capture the Flag Competitions

CTFs contain cybersecurity challenges where participants solve problems to obtain flags.

Common categories include:

- Web
- Cryptography
- Forensics
- OSINT
- Reverse Engineering
- Binary Exploitation
- Networking
- Linux
- Windows
- Programming

CTFs are excellent for developing practical cybersecurity skills.

---

# Collegiate Cyber Defense Competition

CCDC focuses primarily on defending and maintaining business systems.

Members may need to:

- Secure Linux servers
- Secure Windows servers
- Configure firewalls
- Monitor networks
- Analyze logs
- Respond to incidents
- Maintain business services
- Write incident reports

CCDC is primarily a defensive competition.

Recommended experience level:

Intermediate to Advanced

---

# Collegiate Penetration Testing Competition

CPTC focuses on penetration testing in a professional environment.

Participants perform authorized security assessments and produce professional reports.

Skills include:

- Reconnaissance
- Enumeration
- Network penetration testing
- Web application testing
- Active Directory
- Privilege escalation
- Documentation
- Reporting
- Presentations

Recommended experience level:

Intermediate to Advanced

---

# CyberForce Competition

CyberForce combines cybersecurity defense, system administration, incident response, and business operations.

Skills may include:

- Linux
- Windows
- Networking
- Firewalls
- Monitoring
- Incident response
- System administration
- Security hardening

Intermediate to Advanced

# MITRE Embedded Capture the Flag

MITRE eCTF focuses on embedded systems security.

Important skills include:

- C
- Embedded programming
- Cryptography
- Hardware
- Reverse engineering
- Secure design
- Software security

Recommended experience level:

Intermediate to Advanced

---

# Competition Rules

Always follow the rules and scope of the competition.

Do not:

- Attack systems outside competition scope.
- Share active competition flags.
- Publish restricted competition materials.
- Share credentials.
- Attack other competitors unless explicitly permitted.
- Use prohibited tools or techniques.

If you are unsure whether something is allowed, ask the competition organizers or a club officer before doing it.

---

# Getting Involved

Members interested in competing should:

1. Attend club meetings.
2. Participate in practice sessions.
3. Complete CTF challenges.
4. Learn the fundamentals.
5. Talk with competition team leads.
6. Participate in team tryouts or training when applicable.

You do not need to be an expert before becoming involved.

Training and practice are part of the competition experience.
