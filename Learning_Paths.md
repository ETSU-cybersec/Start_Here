# Cybersecurity Learning Paths

Cybersecurity contains many different specialties.

New members should first build a strong technical foundation before specializing.

## Core Fundamentals

All members should learn:

1. Linux
2. Windows
3. Networking
4. Git
5. Python
6. Bash
7. Cybersecurity Fundamentals

After learning the fundamentals, choose an area that interests you.

---

# Penetration Testing

Recommended progression:

1. Linux
2. Networking
3. Python and Bash
4. Web Fundamentals
5. Nmap
6. Web Enumeration
7. Burp Suite
8. Web Vulnerabilities
9. Linux Privilege Escalation
10. Windows Fundamentals
11. Windows Privilege Escalation
12. Active Directory
13. Reporting

Important topics:

- Reconnaissance
- Enumeration
- Vulnerability identification
- Web application security
- Network security
- Privilege escalation
- Active Directory
- Password security
- Reporting

---

# Blue Team / SOC Analysis

Recommended progression:

1. Networking
2. Linux
3. Windows
4. Logs
5. Wireshark
6. SIEM fundamentals
7. Threat detection
8. Incident response
9. Threat intelligence
10. Threat hunting

Important topics:

- Log analysis
- Network traffic analysis
- SIEM
- Endpoint security
- Incident response
- Threat intelligence
- Detection engineering
- Threat hunting

---

# Digital Forensics

Recommended progression:

1. Linux
2. Windows
3. File systems
4. File metadata
5. Network forensics
6. Disk forensics
7. Memory forensics
8. Timeline analysis

Important tools include:

- Wireshark
- Autopsy
- Volatility
- ExifTool
- binwalk
- strings

---

# Reverse Engineering

Recommended progression:

1. C
2. Computer architecture
3. Assembly
4. Linux processes
5. GDB
6. Ghidra
7. Static analysis
8. Dynamic analysis

Important topics:

- x86 and x86-64 assembly
- Registers
- Memory
- Stack
- Heap
- Calling conventions
- Executable formats
- Debugging

---

# Malware Analysis

Recommended progression:

1. Linux
2. Windows
3. Networking
4. C
5. Python
6. Assembly
7. Reverse Engineering
8. Static Malware Analysis
9. Dynamic Malware Analysis

Malware should only be analyzed inside properly isolated and authorized lab environments.

Recommended progression:

1. Linux
2. Networking
3. Python
4. Web fundamentals
5. Cryptography fundamentals
6. Forensics
7. Reverse engineering
8. Binary exploitation

Common CTF categories include:

- Web
- Crypto
- Forensics
- OSINT

- Binary Exploitation

- Linux
- Windows

# Cloud Security

Recommended progression:

1. Networking
2. Linux
3. Web fundamentals
4. Identity and Access Management
5. AWS, Azure, or Google Cloud fundamentals
6. Cloud networking
7. Cloud logging
8. Cloud security monitoring

---

# Embedded Security

Recommended progression:

1. C
2. Computer architecture
3. Electronics fundamentals
4. Embedded programming
5. Cryptography
6. Reverse engineering
7. Hardware security

This path is particularly useful for competitions such as MITRE eCTF.
