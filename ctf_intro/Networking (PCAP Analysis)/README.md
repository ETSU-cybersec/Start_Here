# Network Analysis
## The process of capturing and viewing packets on a network to look for particular information
  - Mostly uses wireshark, an application available on Windows/Linux/Mac
  - Involves looking through traffic and filtering for particular protocols to determine what occured
  - Can be as simple as looking for the IP of a computer reaching a certain network
  - Can be much more complex, looking for passwords, usernames, or other more specific information
