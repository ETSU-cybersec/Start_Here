# There are many different categories inside of CTFs, but below are the most common ones:

## WEB)
    - Web Exploitation is focused on using cross site scripting, SQL injection, and other web based attacks to find flags by finding vulnerabilities on a website.

## FORENSICS)
    - Digging through data online to find specific info about someone, or going through old files/PCAP (wireshark) data to learn about conversations that were had.

## REVERSE)
    - Reverse Engineering is focused on breaking through insecure code to find flags. ex. breaking insecure encryption

## PWN)
    - Red Teaming is all about gaining access to a system, pwning is usually focused on gaining root access and finding a flag by doing so.

## OSINT)
    - Open Source Intelligence is about using online tools to find specific locations in the world. ex. what hotel someone was staying at.

## CRYPT)
    - Cryptography is about breaking codes in order to reveal hidden messages. ex. Ceaser Cypher, ROT13, anything you have to decode.

## MISC)
    - These are usually just challenges that don't fit into these other categories, usually have to do with math or extremely strange/complicated problems.

## BINARY)
    - Binary Exploitation is the process of finding and abusing flaws in compiled programs—like buffer overflows or memory corruption. This is usually done deep in the compiler (aka. assembly exploitation)

## STEGO) 
    - Steganography is hiding and extracting information from images, audio, or other media.
