# Steganography

## It is the process of hiding secret information inside of an ordinary file.
  - used to hide information from anyone but the intended recipient
  - a real life example would be using an image or audio file to send sensitive data out of an organization for malicious purposes


# CTF Usage

## CTF challenges often hide flags inside of images or audio files.
  - Often contain other images or zipped files which lead to the flag
  - Suspect files can be run through a variety of tools to detect and extract hiddden information
