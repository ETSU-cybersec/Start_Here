# There are several vulnerability scanning tools available
## Nikto
  - Vulnerability scanner
      - finds misconfigurations, outdated software, and vulnerabilities
  - Basic usage is Nikto -h <ip.Adress.Here>
      - Can add -p <port> to the end to specify a port
  - Cheatsheet: https://hackviser.com/tactics/tools/nikto

## ffuf
  - This is a fuzzing tool
      - Allows you to find directories / file names
  - Cheatsheet: https://cybertutorials.org/ffuf-cheat-sheet/

## GoBuster
  - This is a directory fuzzing tool
      - Allows you to find hidden / misconfigured directories
  - Can also be used to find subdomains
  - Cheatsheet: https://abrictosecurity.com/gobuster-directory-enumerator-cheat-sheet/

## Hydra
  - Bruteforce password / login cracking
  - Cheatsheet: https://pentesting.site/cheat-sheets/hydra/
